# Model Inventory

The typed inventory records model ID, version, family, type, purpose, owner, developer, validator, legal entity, jurisdiction, materiality, tier, lifecycle status, validation dates, monitoring frequency, inputs, outputs, upstream and downstream systems, reports, issues, limitations, restrictions, approval status and retirement date.

Synthetic model examples include:

- Retail PD logistic model.
- Gradient boosting PD challenger.
- Collateral LGD model.
- Fraud alert classifier.
- Finance baseline forecast.
- AML typology rule set.
- Retired PD model version.

Model ID and version combinations must be unique. The independent validator cannot be the same synthetic role as the developer.
