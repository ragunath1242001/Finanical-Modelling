# Model Monitoring

Monitoring compares reference, validation and current production periods.

Tracked examples include:

- AUC;
- Brier score;
- calibration error;
- PSI;
- missing-income rate;
- override rate;
- false-positive rate;
- forecast bias.

Statuses are Green, Amber, Red or Not Available. A red breach can create a model-risk finding, trigger use-restriction assessment and initiate revalidation.

Thresholds are educational and configurable. They are not universal institutional policy.
