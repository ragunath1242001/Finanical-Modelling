# CV And LinkedIn Examples

## One CV Bullet

Built an independent educational banking risk and governance platform in Python and Streamlit, integrating credit-risk parameters, IFRS 9 lifetime ECL, capital-impact analysis, BCBS 239 controls, model monitoring and audit workflows using synthetic data.

## Three CV Bullets

- Developed modular Python risk engines for PD, LGD, EAD, lifetime ECL, scenario weighting, provision bridges, capital bridges, Basel-style RWA and stress testing.
- Implemented BCBS 239-style controls, Risk-versus-Finance reconciliation, lineage, 1LOD/2LOD issue workflow, evidence records and audit logging on synthetic data.
- Added model-risk management features including inventory, validation findings, monitoring thresholds, PSI drift, use restrictions, revalidation triggers and explainability outputs.

## LinkedIn Project Description

I built an independent European Banking Risk & Governance Lab with Python and Streamlit to understand how credit risk, IFRS 9, Basel capital, stress testing, data governance and model risk connect. The app uses synthetic data and simplified educational assumptions, with clear disclaimers that it is not a production or regulatory-compliance system.
