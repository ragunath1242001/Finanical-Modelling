# Model Validation

The validation framework covers:

- conceptual soundness;
- data quality;
- methodology;
- implementation verification;
- performance;
- calibration;
- discrimination;
- stability;
- sensitivity;
- benchmarking;
- explainability;
- limitations;
- governance;
- documentation;
- regulatory relevance;
- use appropriateness.

Validation outcomes are Pass, Pass with Conditions, Fail or Not Assessed.

Findings include model ID, version, dimension, title, description, severity, recommendation, owner, due date, status, evidence and linked governance issue.

Developers provide development evidence. Independent validators challenge that evidence; they should not independently validate their own model.
